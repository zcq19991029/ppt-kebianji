# 教学图对象级复现

本技能只负责复现已有确定版本原图，不重新策划、不生图、不把整张原图铺底后覆盖文字。普通文字、标签、卡片、结构线、箭头、流程关系和可重建几何图形必须是 PPT 原生对象；复杂机器人、设备、照片、品牌标志和风格插图可作为独立位图，但必须先经过源图对照的资产分离。

## 启动时必须完成

1. 先读父级 `AGENTS.md`、复现项目 `README.md`、`项目交接.md`，再读取本任务实际原图、复现清单、唯一索引、必要独立素材和模板；不要依赖旧聊天摘要或扫描无关项目。
2. 核对输入路径、源图哈希、像素尺寸、任务名、完整页序、模板/无模板、分别或合并输出。名称、模板或输出方式不确定时集中提问并等待真实答复；已确认项不重复询问。
3. 检查视频占位页。视频页不送 OCR、资产分离或复刻；合并输出时保留来源页号、输出页号和“疑似/确认视频、需要用户手动添加”的原生占位说明。
4. 运行 `editppt --help`、`editppt doctor`。先 `editppt prepare`，再按公共 `image-to-editable-ppt` 技能生成 worker prompt，并用 `editppt run dispatch --local`（单页）或真实 page worker（多页）取得写入许可；不得绕过 run 状态。

## 强制流水线

详细执行表见 [references/reconstruction-workflow.md](references/reconstruction-workflow.md)，以下顺序不可省略：

1. **原图与 OCR 双重盘点**：用 OCR 识别文字位置、字号组和文本内容，但 OCR 只提供候选；逐项回看原图，纠正错字、漏字、断行、标点、数字和中英文混排。建立 `text_inventory`、`visual_inventory`、关系清单和源像素坐标表。
2. **背景决策**：白底、纯色、普通卡片、规则渐变和结构线优先用原生对象；复杂背景只有在去除待重建前景后仍需保留时才走图像编辑。禁止把 `source.png` 整图当背景。
3. **前景资产分离**：所有复杂图标/插图/标志通过 `image_gen.imagegen` 源图编辑资产表，再 `editppt image import`、`process-sheet` 分离。逐个查看资产表和分割结果，核对对象身份、方向、颜色、完整边缘和原图位置；错误资产必须返工，不能用近似图标、源图裁剪或 native 形状替代。
4. **原生对象重建**：普通文字和结构按 `manifest.json` 的 `box_px`、`points_px` 写入；同级文字统一字号；连续曲线是一个 path；箭头保留端点；卡片角半径按原图分类；表格使用 native table。所有图片、文字和形状都必须有源像素坐标。
5. **构建与三层对照**：运行 `editppt page build`、`page contact-sheet`、`page validate`，同时渲染 PPT 预览，和 source.png 做整图、三分区、局部对象三层对照。检查文字内容/坐标、对象身份、层级、方向、连接关系、遮挡、裁切、比例、字号和颜色意义。
6. **内容修复闭环**：任何漏字、错字、资产错位、错误对象、错误箭头、关系错误或遮挡都必须回到 manifest/资产分离阶段修复，再 build、render、validate；不得用 `passed`、文件存在或 OCR 分数掩盖视觉错误。保留失败证据和修复原因。
7. **记录与最终组装**：只有页面 `validation.json` 顶层 `passed: true` 才能 `run record`；所有页记录后才 `run finalize`。最终再做 PPTX zip/媒体/页数/文本覆盖/manifest 资源检查，并用可用的 OfficeCLI 或原生 Office/WPS 渲染检查；工具不可用时如实记录边界。

## 交付与返工

任务目录只写本次复现的 PPTX、预览、验证报告和公共运行资料；不改上游原图、模板、提示词或生图任务。正式输出默认是 `任务名-可编辑版.pptx`，先另存验收，不覆盖已有成品。报告必须分别说明：可改字对象、可移动/替换对象、仍为位图对象、结构验证、OCR/视觉对照、实际渲染/打开检查、已知差异和未验证边界。

用户给出 PPT 批注、截图或“请对比原图”时，批注是返工输入：逐条定位对象 ID/坐标，与原图对照，修复后重新渲染并逐条复核；不能只回复“已知差异”。

完成本阶段后先报告文件路径和验证状态，再询问“检查或修订 / 结束”。
